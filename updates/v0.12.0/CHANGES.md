# v0.12.0 — 결과 표시 및 조작 개선

## 적용 방법

이 패치는 v0.11.0 / v0.11.1에 적용합니다. v0.11.1 시작 오류 수정도 포함합니다.
새 라이브러리나 솔버 다운로드·설치는 없으며 기존 설치를 재사용합니다.

1. Manager와 결과 창을 닫습니다.
2. `system_drop_v0.12.0_update.zip` **전체**를 임시 폴더에 압축 해제합니다.
3. `apply_update.bat`을 실행합니다.
4. 폴더 선택 창에서 **기존 `start_windows.bat`이 있는 `system_drop` 폴더**를 선택합니다.
5. 완료되면 기존 `start_windows.bat`을 실행합니다.

변경 파일은 기존 설치의 `backups/before_v0.12.0_날짜시간`에 먼저 백업합니다.
설치 버전, 폴더 구조와 패치 SHA-256을 확인한 후 복사합니다. 복사 실패 시 변경 파일을 복원합니다.
`runs`, 템플릿 INP, 사용자 설정, 라이브러리, 솔버는 덮어쓰지 않습니다.

PowerShell을 실행할 수 없는 환경에서는 `payload` **안의 내용**을 기존 프로그램 폴더에
복사·병합하여 덮어쓸 수 있습니다. `payload` 폴더 자체를 복사하는 것이 아닙니다.
기존 프로그램 폴더와 사용자 데이터를 먼저 백업하세요.

## 결과 창

- Max 주석은 불투명한 흰색 박스를 선보다 앞에 배치합니다. 연결선은 박스 가장자리에서 시작합니다.
  표기는 `Max 22.543 MPa`처럼 값·단위만 표시하며 파트명/노드 ID는 표시하지 않습니다.
  변위·속도에는 각각 mm, mm/s를 표시합니다. 박스는 계속 드래그할 수 있습니다.
- 범위 고정 Min/Max는 소수점 세 자리입니다.
- 결과 이름: Displacement, Velocity, Von-Mises Stress, Max. Principal Stress,
  Min. Principal Stress 및 S11/S22/S33/S12/S23/S13. 각 물리량에 단위를 표시합니다.
  텐서는 XX/YY/ZZ/XY/YZ/XZ 대칭 성분으로 계산합니다. 주응력은 선택한 평균화 텐서의 고유값입니다.
  Source에서는 기존 내보낸 Von-Mises 값이 있으면 그 값을 유지합니다.
- 평균화 임계값, 컨투어 단계 수, 파트 컨투어·불투명도, 변형 배율, 바닥 불투명도 폭을 늘렸습니다.
  색상 버튼은 줄였습니다.
- 해석 출처가 확인되면 `Calculix - PyVista (Open-Source)` / `Abaqus - PyVista (Open-Source)`로 표시합니다.
  출처 정보가 전혀 없는 외부 VTU는 추측하지 않고 일반 PyVista 제목을 유지합니다.
- 일반 재생과 연속재생은 각각 기호 버튼 하나로 재생/멈춤을 전환합니다.
- 하단 시간은 고정 폭·고정 소수점, 정확한 시간은 마우스 툴팁입니다. 시간 변화가 다른 컨트롤을 밀지 않습니다.
- 화면 탭의 음영 농도 0–100%를 조절할 수 있습니다. 기본 65%이며 밝은 면과 측면의 차이를 강화했습니다.
- 격자를 꺼도 파트의 경계·특징 선을 표시합니다. 내부 평면 격자선은 표시하지 않습니다.
- 3D 배경은 흰색이며 스크린샷과 동영상에도 반영됩니다.

## 마우스

[Altair 2021 HyperMesh/HyperWorks 방식 설명](https://2021.help.altair.com/2021.1/hwdesktop/hc/hc_mousehandling.htm)을 참고하여
클래식 조합을 적용했습니다. 기존 회전/이동/확대 선택 메뉴는 제거했습니다.

- Ctrl + 왼쪽 드래그: 회전. 짧게 클릭하면 제품의 회전 중심을 선택합니다.
- Ctrl + 오른쪽 드래그: 이동.
- Ctrl + 가운데 드래그: 사각 영역 확대. 짧게 클릭하면 맞춤.
- 휠: 확대/축소. F: 맞춤. I: 등각 보기.

영역 확대는 사각형 선택이며 HyperMesh의 자유 곡선 방식과 완전히 동일한 구현은 아닙니다.

## 방향 목록

행 높이 21 → 23px, 아이콘 32×20 → 36×22px로 소폭 늘렸습니다.
모식도는 제품 304:212:16 비율과 실제 낙하 벡터를 사용하고 바닥을 고정합니다.
Top/Bottom, Front/Rear 면의 색 농도를 구분하고 숨은 면 그리기 순서를 수정했습니다.
두께 방향 모서리가 먼저 닿는 Corner를 유지합니다.
모서리 도식이 카메라에 겹쳐 선처럼 보이지 않도록, 바닥 수직축 주위의 보기용 회전만 보정합니다.
해석에 사용하는 방향·각도는 변경하지 않습니다.
`template_calculix_reference`는 향후 배포에서 제외합니다.

## 검증

- 자동 테스트 182개 통과. 응력 고유값, 평균화 순서, 원본 응력 유지, Corner 접촉선·비율 포함.
- 실제 Linux Qt/VTK 화면에서 표시, 범위, 재생 토글, 고정 컨트롤 위치, 클래식 회전/이동/영역 확대,
  특징 선, 음영과 18행 표시 확인.
- GIF 프레임 간격 내보내기 확인.
- Windows PowerShell 업데이트 실행과 실제 Windows 렌더링은 이 환경에서 미검증입니다.
- 해석 알고리즘과 입력 조건은 변경하지 않았으며 기존 솔버 계산을 반복하지 않았습니다.
