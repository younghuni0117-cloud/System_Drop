# v0.12.1 — GUI 시작 인수 전달 오류 수정

v0.12.0의 시작 스크립트가 내부 `--gui` 옵션을 소비한 후에도 `sys.argv`에 남겨
`gui.py`에 넘기고 있었습니다. GUI가 이 옵션을 다시 해석하면서
`unrecognized arguments: --gui`로 종료되는 오류를 수정했습니다.

- GUI 실행 전에 `sys.argv`를 GUI 진입 파일명과 GUI 전용 옵션으로 새로 구성합니다.
- 격리 모드 경로 보정과 기존 라이브러리 재사용은 유지합니다.
- 실제 인수 파서를 사용하는 회귀 테스트로 같은 오류를 검사합니다.
- 설치/실행 BAT에서 정상 종료 시 실패 처리로 빠지지 않게 하고 오류 때 중복 대기를 제거했습니다.
- 업데이트 도구가 패치 manifest의 버전으로 지원 범위와 백업 폴더를 결정합니다.

## 설치

v0.11.0, v0.11.1, v0.12.0에 적용할 수 있는 누적 패치입니다.
v0.12.0 결과 창 개선과 v0.11.1 시작 경로 수정도 모두 포함합니다.

1. Manager와 결과 창을 닫습니다.
2. `system_drop_v0.12.1_update.zip` 전체를 임시 폴더에 압축 해제합니다.
3. `apply_update.bat` 실행.
4. 기존 `start_windows.bat`이 있는 `system_drop` 폴더 선택.
5. 업데이트 완료 후 기존 `start_windows.bat` 실행.

추가 라이브러리 설치는 없습니다. 기존 모델, 설정, 결과, 솔버와 라이브러리는 유지합니다.
변경 파일은 `backups/before_v0.12.1_날짜시간`에 백업합니다.
PowerShell을 사용할 수 없으면 백업 후 `payload` 안의 내용을 기존 설치 폴더에 병합하여 덮어쓰세요.

## 확인

격리 모드에서 GUI 인수 처리를 검사하고, Linux Qt 환경에서 실제 bootstrap 실행 →
기존 라이브러리 확인 → GUI 창 생성·스크린샷 → 정상 종료 경로를 검사했습니다.
실제 Windows 실행은 이 개발 환경에서 미검증입니다.
