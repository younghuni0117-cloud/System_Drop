# v0.12.4 — 대용량 결과 변환의 MemoryError 개선

## 확인된 원인

데스크탑의 `conversion_error.txt`에 **MemoryError**가 기록됐습니다.
이 경우 솔버 계산은 정상 종료했고 Python의 결과 변환 과정에서 메모리가 부족한 것입니다.
기존 변환기는 FRD 전체 프레임의 절점 배열·VTK 격자와 DAT 전체 응력을 한꺼번에 저장한 뒤
필요한 프레임을 골랐기 때문에 종료 시간이 길어지면 메모리 요구량이 크게 증가했습니다.

노트북에서 99.9%가 오래 표시된 현상 역시 완료 후 변환 시간과 관련될 수 있습니다.
PC별 메모리와 파일 읽기 속도에 따라 결과가 달라지며, 다른 오류가 함께 있는지는 로그로 별도 확인합니다.

## 수정

- 원본 FRD/DAT를 순서대로 검사하고 시간·파일 위치만 인덱스에 보관합니다.
- 선택한 실제 프레임을 한 프레임 단위로 읽어서 VTU에 저장합니다.
  전체 절점/요소 이력을 RAM에 올리지 않습니다.
- 선택하지 않는 프레임도 원본 숫자·성분 검사를 수행합니다.
  잘못된 데이터나 NaN을 무시해서 성공으로 처리하지 않습니다.
- 기존 시간 반올림 복원, 출력 프레임 선정, 응력 IP 평균과 최대값 계산을 유지합니다.
- 솔버 입력·출력 빈도, 물성, native restart와 누적 상태 전달은 변경하지 않습니다.
- 솔버 종료 뒤 버튼은 **결과 변환(XX%)**으로 바뀝니다.
  FRD/DAT 검사 바이트 수와 저장한 프레임 수를 기준으로 표시하며 최종 상태 검사 중에는 **최종 검증 중**으로 표시합니다.
  검증까지 성공해야 **완료**가 됩니다.
- 변환 진행과 MemoryError 등 예외 이름을 로그에 표시합니다.

변환 진행률은 검사 작업에 80%, 프레임 저장 작업에 20%를 배정한 작업량 표시입니다.
남은 시간 예측값이나 솔버 시간 진행률은 아닙니다. 큰 파일은 계속 읽어야 하므로 처리 시간 자체가 없어지지는 않습니다.

## 적용 및 재계산 없이 복구

1. 데스크탑의 실패한 doe 폴더 전체를 보존합니다. FRD/DAT/job.rout/solver_completed.json을 변경하지 마세요.
2. Manager와 결과창을 닫습니다. 노트북에서 별도 계산이 계속 진행 중이면 그 계산은 그대로 두어도 됩니다.
3. 업데이트 ZIP 전체 압축 해제 → **apply_update.bat** → 기존 start_windows.bat이 있는 설치 폴더 선택.
4. 프로그램 재실행 → 상세 옵션 → **이전 실행 폴더 열기 / 재개** → 실패한 doe 폴더 선택.
5. **자동 실행** 또는 실패한 단계 버튼을 누릅니다.

완료 기록의 해시·native 상태 검사가 통과하면 **기존 솔버 정상 종료 결과 확인: 재계산 없이 결과 변환/검증부터 재시도합니다.**라는 로그와 함께 변환만 재시도합니다.
입력이나 원본 결과를 수정하여 검사를 통과하지 못하면 자동 재계산을 중단합니다.
완료된 다른 단계, 기존 템플릿·설정·라이브러리·솔버는 유지합니다.

## 실제 검증

- 자동 테스트 **197개 통과**. Windows 3자리 지수 FRD, 반복된 반올림 시간,
  DAT 텐서 평균·전단 순서, 잘못된 미선택 프레임 검출, 취소와 기존 계산 재사용을 포함합니다.
- 실제 CCX 출력 **FRD 178,994,018바이트 + DAT 344,424,603바이트**, 원본 1,131프레임을 재변환했습니다.
- 선택한 6프레임의 **72개 결과 배열과 최종 상태가 기존 변환 결과와 완전히 일치**했습니다.
- 해당 Linux 시험의 최대 RSS는 **약 69.5 MiB**, 변환 시간은 약 36초였습니다.
  이 수치는 해당 샘플·실행 환경 측정값이며 모든 PC/모델에서 같은 메모리나 시간을 보장하지 않습니다.
- 별도 실제 계산 완료 폴더에 MemoryError 실패 기록을 두고 복구했습니다.
  솔버 실행을 금지한 상태에서 **원본 변경 없이 변환만 완료**했고 다음 안정화 단계로 진행할 수 있었습니다.
- 실제 Qt 화면의 변환/최종 검증 표시를 확인했습니다.
- 실제 Windows 실행은 이 개발 환경에서 미검증입니다.

라이브러리를 새로 설치하거나 재설치하지 않는 누적 패치입니다.
